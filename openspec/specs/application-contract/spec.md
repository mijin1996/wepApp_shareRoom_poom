# application-contract Specification

## Purpose
서류 1장으로 신청하고, 서류 확인 · 승인 뒤 서명 · 결제하면 그날 입주 안내가 열린다. (REQ_003 ~ 012, POL_HOUSE · POL_ROOM · POL_PRIVACY_03)

## Requirements

### Requirement: 간단 신청

본인인증한 사용자는 **부모 나이와 관계없이** 3단계(입주일 · 기간 → 자녀 나이대 · 성별 → 연락 시간 · 상담 언어 · 서류 1장)로 신청할 수 있어야 한다(SHALL). 서류는 [나중에 올릴게요]로 미룰 수 있지만 **항상 입주 전에** 내야 하며, 서명 · 결제 · 입주 안내(주소) 모두 서류 확인이 끝나 있어야 한다(SHALL).

#### Scenario: 서류 없이 신청
- **WHEN** 서류를 나중에 올리기로 하고 신청한다
- **THEN** 신청이 접수되고 "계약 전에 서류 1장이 필요해요"가 보인다

#### Scenario: 진행 중 신청
- **WHEN** 진행 중인 신청이 있는데 다른 방을 신청한다
- **THEN** `APPLY_409` "이미 진행 중인 신청이 있어요"

### Requirement: 신청 자격 규칙

엄마 하우스는 엄마만, 아빠 하우스는 아빠만 신청할 수 있어야 하며(SHALL), 가족보다 작은 방은 `ROOM_422`, 6인 이상 가족은 상담 연결, 입주 중인 방은 `ROOM_410`이어야 한다(SHALL).

#### Scenario: 작은 방
- **WHEN** 9살 아들 + 10살 딸 가족이 침실 2개 방을 신청한다
- **THEN** `ROOM_422`

### Requirement: 서류 확인 전 계약 잠금

승인되고 서류가 확인되기 전에는 서명 · 결제 · 입주 안내가 열리지 않아야 한다(SHALL).

#### Scenario: 서류 확인 전 서명
- **WHEN** 승인된 신청자가 서류 확인 전에 서명한다
- **THEN** `DOC_428`

#### Scenario: 끝까지
- **WHEN** 운영 매니저가 서류를 확인하고, 신청자가 계약서를 끝까지 읽고 서명한 뒤 결제한다
- **THEN** 입주 안내에 주소 · 출입 방법 · 규칙이 보이고 방은 입주 중이 된다

#### Scenario: 결제 실패
- **WHEN** 결제사가 거절한다
- **THEN** `PAY_402` 안내가 보이고 방은 잡아 둔 상태로 남는다

### Requirement: 자격은 자녀 나이만

부모 나이는 묻지 않고 신청을 막는 데 쓰지 않아야 한다(SHALL). 신청에는 만 24세 이하 자녀가 1명 이상 있어야 한다(SHALL).

#### Scenario: 자녀 없음
- **WHEN** 자녀 없이 신청한다
- **THEN** `COMMON_400`

### Requirement: 내 상황 · 급한 정도

신청서는 선택 항목으로 "내 상황 자세히"(1000자)와 급한 정도(오늘 · 내일 / 1주 / 한 달)를 받아야 하고(SHALL), 이 내용은 운영 매니저만 볼 수 있어야 한다(SHALL). "오늘 · 내일 당장"이면 운영 매니저에게 긴급 알림을 보내야 한다(SHALL).

#### Scenario: 당장 필요
- **WHEN** 급한 정도를 "오늘 · 내일 당장"으로 골라 신청한다
- **THEN** 운영 매니저에게 "🚨 당장 필요" 긴급 알림이 간다
