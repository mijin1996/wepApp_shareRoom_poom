# room-search Specification

## Purpose
한부모가 원하는 지역 · 입주일 · 가족 구성으로 방을 찾고, 정확한 위치는 결제 전까지 보호한다. (REQ_001 · 024 · 030 ~ 036, POL_SEARCH)

## Requirements

### Requirement: 3칸 검색

검색창은 "어디로 · 언제부터 · 누구와" 세 칸으로 구성되어야 한다(SHALL). "어디로"는 지역(구 · 동) · 역 · 학교 · 어린이집 · 하우스 이름을 한글 · 초성 · 영문으로 추천해야 한다(SHALL).

#### Scenario: 초성 검색
- **WHEN** 사용자가 "ㅁㅇ"을 입력한다
- **THEN** 망원동 · 망원역 · 망원초등학교가 종류별로 추천된다

#### Scenario: 영문 검색
- **WHEN** 사용자가 "Mapo"를 입력한다
- **THEN** 마포구(Mapo-gu)가 추천된다

### Requirement: 가족에 맞는 방만 보여 주기

"누구와"에 자녀가 있으면 최저주거기준으로 계산한 필요 침실 수 · 최소 면적 이상인 방만 목록 · 지도에 보여야 한다(SHALL).

#### Scenario: 남매 가족
- **WHEN** 엄마 + 9살 아들 + 11살 딸로 검색한다
- **THEN** 침실 3개 이상 방만 보이고 각 카드에 "우리 가족에 맞아요"가 보인다

### Requirement: 위치 보호

목록 · 상세 · 지도 · API 응답에는 동 단위 위치만 있어야 하며(SHALL), 정확한 좌표 · 주소 · 출입 정보는 결제 후 입주 안내에서만 보여야 한다(SHALL). 걸어서 ○분은 5분 단위로 올림해야 한다(SHALL).

#### Scenario: 지도
- **WHEN** 사용자가 지도를 연다
- **THEN** "망원동 · 월 25만 원~ · 빈방 2" 같은 동 묶음만 보이고 건물 위치 핀은 없다

### Requirement: 결과 0건과 지역 수요

결과가 0건이면 조건 넓히기와 [이 지역에 생기면 알림]을 보여 주고(SHALL), 알림 신청은 구 · 가족 크기 · 가격대 숫자로만 집계해야 한다(SHALL).

#### Scenario: 노원구
- **WHEN** 하우스가 없는 노원구로 찾고 [생기면 알림]을 누른다
- **THEN** 운영 콘솔 지역 수요에 "노원구 · 3인 · ~30"이 1 늘고 이름 · 전화번호는 남지 않는다
