# responsive-i18n Specification

## Purpose
휴대폰 세로 · 가로, 폴더블, 태블릿, PC 어떤 비율에서도 버튼이 가려지거나 글이 넘치지 않고, 한국어 · 영어로 모든 화면을 쓴다. (POL_LANG, D05 §2)

## Requirements

### Requirement: 버튼 글 넘침 없음

모든 버튼 · 링크 버튼 · 칩 · 탭의 글은 버튼 안에서 줄바꿈되어야 하며(SHALL) 버튼 밖으로 나가거나 화면 가로 밖으로 나가지 않아야 한다(SHALL). 버튼 높이는 40px 이상(주요 버튼 48px)이어야 한다(SHALL).

#### Scenario: 폴더블 겉화면
- **WHEN** 280×653 화면에서 홈 · 방 찾기 · 방 상세 · 신청 · 안내 화면을 연다
- **THEN** 가로 스크롤이 생기지 않고 모든 버튼 글이 버튼 안에 있다

### Requirement: 아래 고정 버튼은 항상 보임

방 상세 · 신청의 아래 고정 버튼 줄과 시트의 버튼 줄은 탭바 · 홈 바(안전 영역) 위에 항상 보여야 한다(SHALL). 시트는 내용만 스크롤되어야 한다(SHALL).

#### Scenario: 휴대폰 가로
- **WHEN** 812×375 가로 화면에서 방 상세를 연다
- **THEN** 탭바 대신 위 메뉴가 보이고 [이 방 신청하기]가 화면 안에 보인다

### Requirement: 한국어 · 영어

모든 화면 문구는 `i18n/ko.json` · `i18n/en.json` 같은 키로 관리하고(SHALL), 키가 다르면 테스트가 실패해야 한다(SHALL). 영어는 `/en` 경로이며 전환 시 같은 화면 · 조건을 유지해야 한다(SHALL).

#### Scenario: 전환
- **WHEN** 방 찾기에서 [EN]을 누른다
- **THEN** `/en/rooms?…` 같은 조건의 영어 화면으로 바뀐다
