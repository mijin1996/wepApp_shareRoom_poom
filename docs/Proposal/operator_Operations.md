## 1. 목적
출시 후 하우스와 서비스를 어떻게 유지 · 키울지.

## 2. 첫 4주
| 주 | 할 일 | 담당 |
|---|---|---|
| 1주 | 1호점 오픈 · 입주 상담 상시 대기 · 신청 2시간 내 전화 (운영 시간) | 운영 매니저 |
| 2주 | 첫 입주자 하우스 규칙 회의 · 공용 공간 청소 순번 | 운영 매니저 |
| 3주 | 지표 리뷰 (신청 → 입주 소요일, 이탈 단계) | PM |
| 4주 | 입주자 인터뷰 3가구 · 개선 목록 → [needFix](common_needFix.md) | PM |

## 3. 지표 리뷰 (매주)
신청 수 · 2시간 연락률 · 입주 소요일 · 공실률 · 연체 · 언어별 신청. 이상 기준: 2시간 연락률 90% 미만, 공실 2주 이상.

## 4. 고객 대응 (CS)
| 유형 | 처리 기한 | 처리 |
|---|---|---|
| 입주 상담 | 운영 시간 2시간 · 그 외 다음 날 오전 | 전화 · 문자 (영어 상담 가능 매니저 1명 이상 배치, 없으면 통역 앱 + 문자) |
| 수리 요청 | 긴급(누수 · 난방 · 잠금) 당일, 일반 3일 | 콘솔 수리 요청 |
| 입주자 갈등 | 3일 | 1:1 상담 → 하우스 회의 → 규칙 위반 경고 |
| 결제 · 환불 · 보증금 | 3영업일 | `POL_PAY` 기준 |

## 4-1. 의견 · 신고 처리
| 주기 | 할 일 | 담당 |
|---|---|---|
| 매일 오전 · 오후 | 신고함 `접수` 0건 만들기 (분류 · 담당 · 첫 답) | 운영 매니저 |
| 바로 | 🛡 안전 신고 → §5 대응 | 운영 매니저 · 대표 |
| 매주 | **주간 분류 회의**: 같은 원인 묶기 · 심각도 · 우선순위 정리 → 고칠 것(`P1` · `P2`)과 기획에 넘길 것(needFix) 나누기, 🏠 민원은 하우스별로 모아 규칙 · 시설 개선 | PM · 운영 매니저 · 개발 리드 |
| 매월 | 평균 처리 일수 · 기한 넘긴 건 · 재신고 비율 · 종류별 추세 → 다음 달 개선 방향 | PM · 대표 |

- 처리는 재현 → 가장 작은 수정 → 테스트판 확인 → 운영 출시(대표 승인) 순서
- 답장 기본형: 고마움 → 무엇이 바뀌었는지 → 다시 해 볼 곳 (한국어 · 영어, 전문 용어 없이)
