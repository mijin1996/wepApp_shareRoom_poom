## 1. 목적
얼마나 빠르고, 안전하고, 안 죽어야 하는지. 인프라 구성 · 비용 기준.

## 2. 기술 구성
| 영역 | 선택 | 이유 |
|---|---|---|
| 프론트 | React + Vite, PWA (홈 화면 추가) | 모바일 웹 중심, 앱 스토어 없이 시작 |
| 호스팅 | Cloudflare Pages (`dist/`만 배포) | 기존 웹앱과 같은 배포 방식 |
| 서버 | Cloudflare Workers | 서버 관리 없음, 무료 구간 |
| DB | Cloudflare D1 | 소규모 관계형 |
| 파일 | Cloudflare R2 (서류 · 계약서 PDF · 방 사진) | 서류 · 계약서는 비공개 버킷 + 서명 URL |
| 본인인증 | 휴대폰 본인인증 업체 (PASS 등) | 만 19세 미만 부모 표시(막지 않음) · 1인 1계정 ([F-09](common_needFix.md#2-정할-것)) |
| 전자계약 | 전자서명 서비스 또는 자체 서명 + PDF | 비용 비교 필요 ([F-09](common_needFix.md#2-정할-것)) |
| 결제 | PG (카드 · 계좌 · 간편결제) + 정기결제 빌링 | 임대료 = 실물 서비스, 인앱결제 대상 아님 |
| 문자 | 문자 발송 API | 신청 · 계약 · 결제 알림 (사용자 언어) · 빈방 알림 |
| 지도 | 국내 지도 API (카카오 · 네이버 중 [F-18](common_needFix.md#2-정할-것)) | 동 단위 묶음 표시, 정확한 좌표는 서버에만 |
| 장소 데이터 | 공공데이터 (학교 · 어린이집 · 역 위치) → `data/places.json` · `HOUSE_POI` | 하우스 등록 때 걸어서 ○분 미리 계산 ([F-19](common_needFix.md#2-정할-것)) |
| 검색 | D1 + 접두어 · 초성 검색 (예: "ㅁㅍ" → 마포) | 데이터가 작아 별도 검색 엔진 없음 |
| 다국어 | 문구 JSON (`i18n/ko.json` · `en.json`) + 경로 `/en/…` | 한국어 · 영어, 이후 언어 추가는 파일만 추가 ([F-12](common_needFix.md#2-정할-것)) |

## 3. 비기능 요구사항
| 분류 | 기준 |
|---|---|
| 성능 | 방 목록 첫 화면 3G에서 3초 이내, 주요 API 500ms 이내, 검색 추천 200ms 이내 (입력 300ms 멈추면 요청) |
| 보안 | HTTPS 전용, 이름 · 전화번호 · 상담 메모 필드 암호화, 서류 · 계약서는 비공개 저장 + 10분짜리 서명 URL, 운영 콘솔 2단계 인증 + 접속 IP 제한 |
| 권한 | 모든 API에서 "내 것만" 서버 판정 (다른 사람 신청 · 계약 id로 조회 불가) |
| 개인정보 | 로그 · 분석 도구에 이름 · 전화번호 · 주소 전송 금지 |
| 가용성 · 백업 | D1 일 1회 백업 30일 보관, 장애 시 4시간 내 복구, 분기 1회 복구 실제 테스트 |
| 모니터링 | 화면 오류는 최근 3분 기록(`window.onerror` · `unhandledrejection` · `console.error` + 화면 이동 · 버튼)으로 신고에 첨부, 결제 웹훅 실패 · 🛡 안전 신고는 운영 매니저 즉시 알림. 이용자가 늘면 오류 추적 도구(Sentry 등) 추가 |
| 배포 | **테스트판 / 운영판** 분리 (§5), 이전 버전 롤백 |
| 접근성 | 글자 크기 확대 대응, 색만으로 상태 구분 금지 |
| 다국어 | 한국어 · 영어 문구 키 100% 일치 (빌드 때 검사), `<html lang>` 언어별, 날짜 · 금액 형식 언어별 |
| 비용 | 하우스 3곳 · 월 방문 1만 기준 인프라 월 5만 원 이하 (본인인증 · 문자 · PG 수수료 별도) |

## 4-1. 의견 · 신고함 구성
| 조각 | 구성 |
|---|---|
| 신고 버튼 · 3분 기록 | 화면 공통 모듈 — 기록은 메모리에만, 같은 것이 이어지면 ×n으로 합침, "12초 전 [누름] 다음" 형식 |
| 화면 사진 | 화면을 이미지(JPEG 0.7)로 — 서류 · 계약 · 결제 · 입주 안내 화면 제외 |
| 받는 곳 | Pages Functions `POST /api/report` → D1 (신고 · 상태 기록), 사진은 R2 비공개 (DB에는 주소만) |
| 요청 제한 | Poom 주소에서 온 요청만 (CORS), 1시간 10건 · 사진 700KB |
| 알림 | 저장 뒤 운영 매니저 메일 · 🛡 안전은 문자까지. 저장 한도를 넘으면 메일로만이라도 전달 |
| 보는 곳 | 운영 콘솔 신고함 (Cloudflare Access 로그인 + 2단계 인증) |

## 4. 외부 서비스 장애 시
| 서비스 | 대체 |
|---|---|
| 본인인증 | "잠시 뒤 다시" + 운영 매니저 전화 신청 접수 |
| PG | 계좌 입금 안내 (운영 콘솔에서 수동 확인) |
| 문자 | 내 집 화면 알림 + 운영 매니저 전화 |

## 5. 테스트판 · 운영판
| 판 | 주소 | 누가 | 올리는 조건 |
|---|---|---|---|
| 내 컴퓨터 | localhost | 개발자 | 자동 테스트 통과 |
| **테스트판** | `dev` 브랜치 미리보기 주소 | 개발자 · QA 테스터 · 초대한 테스터 | 자동 테스트 통과 → 테스트판에 올림 → 시험 신고 1건 접수 확인 |
| **운영판** | 실제 주소 (`main` 브랜치만) | 이용자 | 테스트판에서 확인 + **대표 승인** |
| 롤백 | 이전 버전 고정 주소 | 개발 리드 | 운영 문제 시 바로 |

- 빌드할 때 판 이름 · 버전 · 날짜를 넣어 테스트판 화면 구석에 "테스트판 · v0.1.0 · 날짜" 표시, 모든 신고에 판 정보 첨부 (`REQ_028`)
- 테스트판은 Mock 모드 · 가짜 결제로 동작, 실제 개인정보 입력 금지 안내
- 운영 출시 뒤 운영판 · 테스트판 앱 파일이 같은지 비교
