## 1. 목적
사업으로 출시하고 임대료를 받기 위한 행정 · 법무 항목. 세부 요건은 **신고 전 관할 기관 · 세무사 · 법무 전문가 확인**.

| 분류 | 항목 | 확인할 내용 | 상태 |
|---|---|---|---|
| **사업자** | 사업자 형태 | 주식회사 + (예비)사회적기업 / 사회적협동조합 — 사회주택 · 매입임대 운영기관 자격 요건과 맞춰 선택 ([F-02](common_needFix.md#2-정할-것)) | 대기 |
|  | 업종 | 광고 대행 · 온라인 정보 제공(플랫폼) + 소프트웨어 서비스 — 업종 코드 · 부가세 세무사 확인 | 대기 |
|  | 통신판매업 신고 | 광고 상품을 온라인으로 팔므로 신고. 방 거래는 품이 당사자가 아님을 화면에 고지(통신판매중개자 고지 해당 여부 확인) | 대기 |
| **개인정보** | 제3자 제공 동의 | 문의할 때 이름 · 휴대폰 · 가족 구성 · 내 상황을 **그 광고주에게** 보내는 동의(문의마다), 서류는 고른 광고주에게만 (`POL_INQUIRY_01` · `POL_DOCBOX_01`) | 대기 |
|  | 광고주 의무 | 받은 문의 정보를 임대차 외 용도로 쓰지 않음 · 보관 기간 — 광고 약관 · 위반 시 확인 취소 (`POL_INQUIRY_04`) | 대기 |
| **광고 약관** | 광고 상품 약관 | 30일 · 구독 · 상단 노출 · 문의 과금, 허위 매물 강제로 내림 · 환불 없음, 정산 · 세금계산서 | 대기 |
| **사업 구조** | 품의 위치 | **광고판 + 문의 전달 도구** — 임대인 · 중개인 · 임대관리자가 아님 (§2) | 결정 |
|  | 공인중개사법 | 남의 집 계약을 연결하고 그 대가를 받으면 중개 → **하지 않음**. 품은 **광고판 + 문의 전달 도구**로만 운영 (§2) | 결정 |
|  | 표시 · 광고 | 남의 집(중개대상물) 광고는 공인중개사만 → 광고주는 **공인중개사(등록번호 확인) · 집주인 본인(소유 확인)**만 (`POL_AD_02`). 공인중개사 광고의 필수 표시 항목(중개사무소 이름 · 등록번호 등) 화면 반영, 허위 · 과장 광고 처리 절차 | 대기 |
|  | 후원 · 제휴 | 기업 후원은 **사회공헌 계약**으로, 기부금품법 모집 등록 해당 여부. 제휴 수수료는 업체와 소개 계약 (사업자 형태 [F-02](common_needFix.md#2-정할-것)와 함께) | 대기 |
|  | 숙박업 아님 | 1개월 이상 주거 계약만 — 일 · 주 단위 판매 금지 | 결정 |
|  | 건물 용도 · 소방 | 단독 · 다가구 · 공동주택 용도에서 공유 주거 가능 여부, 소방 시설, 임대형 기숙사 제도 해당 여부 | 대기 |
|  | 최저주거기준 | 방마다 가구원 수별 최소 면적 · 침실 수 충족 확인 (`POL_ROOM`) — 공공 위탁 시 필수 검토 항목 ([F-15](common_needFix.md#2-정할-것)) | 대기 |
|  | 주택임대차보호법 | 입주자 보증금 보호 방법 (보증금 보관 · 보증보험), 확정일자 가능 여부 | 대기 |
|  | 공공 연계 | LH · SH 매입임대 · 사회주택 운영기관 모집 공고 · 자격 ([F-03](common_needFix.md#2-정할-것)) | 대기 |
| **결제** | PG 계약 | 임대료 수납 업종 심사 가능 여부, 정기결제, 정산 주기 | 대기 |
| **사이트 표시** | 사업자 정보 | 상호 · 대표자 · 사업자등록번호 · 통신판매업 번호 · 주소 · 연락처 하단 표시 | 대기 |
| **개인정보** | 처리방침 | 수집 항목 · 목적 · 보관 기간 · 위탁(본인인증 · PG · 문자 · 클라우드) · 국외 이전(클라우드) | 대기 |
|  | 보호책임자 | 지정 · 방침 기재 | 대기 |
|  | 자녀 정보 | 자녀는 나이대 · 성별만 — 부모가 제공, 자녀 본인 계정 없음. 성인 자녀(만 19 ~ 24세)는 계약 동거인으로 본인 동의 서명 | 결정 |
|  | 자격 기준 | 자녀 만 24세 이하는 자체 기준 (한부모가족지원법 아동 기준과 다름) — 약관 · 공공 위탁 계약과 충돌 여부 확인 ([F-14](common_needFix.md#2-정할-것)) | 대기 |
|  | 부모 나이 | 부모 나이는 묻지 않음 (자격은 자녀 만 24세 이하만). 계약 당사자가 미성년일 때 임대차 계약 효력(민법 제5조 법정대리인 동의) 처리는 법률 자문으로 확인 | 대기 |
|  | 범죄 경력 | 범죄경력 자료 제출 요구는 형의 실효 등에 관한 법률상 불가 → 대체 안전장치 ([F-06](common_needFix.md#2-정할-것)) | 대기 |
|  | 검색 · 지도 | 휴대폰 위치는 쓰지 않음(`REQ_040` Won't) → 위치기반서비스 신고 대상 아닌지 확인. 지도 API · 공공데이터 이용 약관 · 출처 표시 | 대기 |
|  | 신고함 | 신고 사진 · 3분 기록 수집 항목 · 보관 기간을 개인정보처리방침에 기재, 신고 창에 함께 가는 것 고지 (`POL_REPORT_03` · `09`) | 대기 |
|  | 안전조치 | 암호화 · 접근 권한 · 접속 기록 ([기술·비기능](developer_Tech_NFR.md) §3) | 대기 |
| **약관** | 이용약관 · 임대차 계약서 | 표준 주택임대차계약서 기반 + 공유 주거 특약 (규칙 · 퇴실 · 공제) — 법무 검토 | 대기 |

## 2. 운영 구조 — 광고판 + 문의 전달 도구
품이 **중개인 · 임대인이 아닌 위치**에 있어야 공인중개사 자격 없이 운영할 수 있음. 구조는 [Business Model](planner_Monetization.md) §1 ~ §3.

| 항목 | 품이 하는 것 | 품이 하지 않는 것 | 법률 상담에서 확인할 것 | 상태 |
|---|---|---|---|---|
| 광고 | 공인중개사 · 집주인 광고를 보여 줌, 광고주 · 광고 내용 확인 | 남의 집을 품 이름으로 광고 | 플랫폼 운영자의 표시 · 광고 책임 범위, 허위 매물 처리 | 대기 |
| 문의 전달 | 가족이 동의한 정보를 고른 광고주에게 전달, 진행 기록 | 조건 협상 · 가격 조정 · 계약서 작성 · 계약 대리 | 전달 · 기록 도구가 중개 행위로 보이지 않는 범위 | 대기 |
| 돈 | 광고주에게 **고정 금액** 광고 상품(30일 · 구독 · 상단 노출 · 문의 1건) | 계약 성사 보수, 계약 금액의 %, 중개보수 나눠 받기, 방값 · 보증금 수납 | **문의당 과금이 성사 보수로 보이지 않는지** ([F-21](common_needFix.md#2-정할-것)) | 대기 |
| 서류 | 가족이 올린 서류를 고른 광고주에게만, 운영 매니저 확인 배지 | 서류를 광고주 전체에 공개 | 민감 정보 처리 · 보관 기간 · 파기 ([F-22](common_needFix.md#2-정할-것)) | 대기 |
| 혜택 · 제안 | 제휴 할인 소개 수수료, 기업 후원 운영비, 기관 연계 계약 | 금융 상품 · 대출 광고 | 소개 수수료 표시, 후원금 처리 방식 | 대기 |

하지 않는 것: 한부모 가족에게 받는 모든 돈, 계약 성사 때마다 받는 보수, 품 이름의 임대 · 전대 · 임대관리.
