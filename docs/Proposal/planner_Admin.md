## 1. 목적
운영 매니저가 DB 접속 없이 방 · 신청 · 계약 · 결제 · 입주자를 관리.

## 2. 메뉴
| 메뉴 | 기능 |
|---|---|
| 대시보드 | 오늘 들어온 신청 · **2시간 넘은 미연락 신청(빨강)** · 영어 상담 필요 표시 · **서류 확인 대기** · 공실 · 연체 · **🛡 안전 신고(빨강)** · 기한 넘은 신고 |
| 신청 | 목록 (상태별) → 상세: 신청 내용 · 상담 메모 · [승인] [보류] [거절 + 사유] · 안전 주의 표시 |
| 방 · 하우스 | 하우스 · 방 등록, 사진, 가격, 입주 가능일, 공실 상태, 건물 유형 · 엘리베이터 · 놀이방 · 주차 · 외국인 · 영어 상담 · 퇴실 청소비 · 최소 계약 기간, 주변 시설 거리 자동 계산 |
| 계약 | 계약서 템플릿 · 발송 · 서명 상태 · 연장 · 해지 |
| 결제 | 결제 · 연체 목록, 계좌 입금 수동 확인, 보증금 반환 처리 |
| 서류 확인 | 신청 상세 안에서 업로드 서류 보기(사유 입력) → [확인 완료] (계약서 발송 가능해짐) / [재요청] → 30일 뒤 자동 파기 |
| 하우스 소식 | 공지 · 수리 요청 처리 · 신고 게시물 숨김 |
| 공고 | 공공임대 · 한부모 공고 등록 · 수정 |
| **신고함** | 의견 · 신고 처리 (§2-1) |
| 지역 수요 | 0건 검색 · 지역 알림을 구 · 동 · 가족 크기 · 가격대로 지도에 표시 — **다음 하우스 위치 판단** |
| 후기 · 자주 묻는 질문 | 후기 확인 후 공개 · 숨김, 자주 묻는 질문 편집 (한국어 · 영어) |
| 제휴 문의 | 집 빌려주실 분 문의 목록 · 상태(새 문의 → 연락 → 현장 확인 → 계약 / 보류) · 메모 |

## 2-1. 신고함 (QA · 민원 관리툴)
| 영역 | 기능 |
|---|---|
| 목록 | 최신순 · 기한 임박순, 거르기: 종류 · 상태 · 심각도 · 하우스 · 판(테스트 / 운영) · 기간 · 담당 |
| 상세 | 내용 (🎤는 글로 바꾼 것 함께) · 화면 사진 크게 · 최근 3분 기록 펼치기 · 화면 위치 · 기기 · 판 정보 |
| 분류 | 심각도(`치명` · `높음` · `보통` · `낮음`, [QA·출시](tester_Release.md) §4) · 우선순위(`P1` 이번 배포 · `P2` 다음 배포 · `P3` 나중) · 담당 · [중복으로 묶기] |
| 상태 | `접수` → `확인` → `처리 중` → `완료` / `보류` · `중복` — 바꿀 때마다 시각 · 처리자 자동 기록 (`POL_REPORT_07`) |
| 처리 기록 | 완료 때 세 줄 필수: **원인 / 고친 것 / 확인 방법**. 고친 판 번호 · 관련 `REQ_` · needFix 항목 연결 |
| 답장 | 신고자에게 짧은 답장 (한국어 · 영어, 전문 용어 없이: 고마움 · 바뀐 것 · 다시 해 볼 곳) |
| 넘기기 | 🏠 · 💳 → 수리 요청 · 결제 메뉴로, 💡 · 🧭 → 기획 검토 목록 (needFix) |
| 숫자 | 종류별 건수 · 평균 처리 일수 · 기한 넘긴 건수 · 재신고(아직이에요) 비율 · 하우스별 민원 수 |

## 3. 권한 등급
| 등급 | 할 수 있는 일 |
|---|---|
| 조회 전용 | 대시보드 · 목록 (개인정보 마스킹) |
| 운영 매니저 | 신청 승인 · 상담 메모 · 서류 확인 · 공지 · 신고 처리 · 신고함 (🏠 · 💳 · 🛡) |
| QA · 개발 | 신고함 (🐞 · 🧭 · 💡) — 재현 · 분류 · 처리 기록, 개인정보 마스킹 |
| 결제 | 환불 · 보증금 반환 · 수동 입금 확인 |
| 슈퍼 관리자 | 계정 · 권한 · 가격 · 계약서 템플릿 |

## 4. 개인정보 보호
- 이름 · 전화번호 기본 마스킹 (`김*희`, `010-****-1234`). 전체 보기 / 서류 열람 시 **사유 입력** 필수
- 모든 작업은 감사 로그 (누가 · 언제 · 누구에게 · 무엇을 · 사유), 삭제 불가

## 5. 운영 시나리오 (DB 없이 처리)
> 신청이 들어오면 대시보드에 뜨고, 운영 매니저가 전화 상담 중 서류를 [확인 완료]하고 [승인]을 누르면 신청자에게 계약서 링크 문자가 가고 방이 72시간 `held`로 바뀌며 감사 로그에 남는다.
