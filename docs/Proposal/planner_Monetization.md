## 1. 목적
매출 구조 · 가격 · 결제 처리. 원칙 3가지:
1. **품은 틀만 만든다** — 방 광고판 · 문의 전달 · 서류함 · 진행 표시. 집 보여 주기 · 조건 · 계약 · 방값은 광고주(공인중개사 · 집주인)와 한부모 가족이 직접
2. **한부모 가족은 0원** — 가입비 · 문의비 · 수수료 없음
3. **계약 성사와 무관한 고정 금액만 받는다** — 계약이 될 때마다 받는 돈은 중개 보수이므로 받지 않음 (공인중개사 자격 불필요, [사업화·법무](owner_Legal.md) §2)

## 2. 누가 무엇을 하나
| 누구 | 하는 일 | 품이 하지 않는 일 |
|---|---|---|
| **품** | 광고판 운영, 광고주 확인(등록번호 · 소유 서류), 광고 내용 확인 · 허위 매물 내림, 문의 전달, 서류함 · 서류 확인 배지, 진행 표시, 혜택 · 제안 창구 | 집 보여 주기, 조건 협상, 계약서 작성, 방값 · 보증금 받기, 입주 관리 |
| **공인중개사** | 매물 광고, 문의 응대, 집 보여 주기, 계약 (중개보수는 공인중개사법대로 가족과 직접) | — |
| **집주인** | 자기 집 광고, 문의 응대, 직거래 계약 | — |
| **한부모 가족** | 방 찾기, 문의, 서류함에 서류 1장 · 보낼 곳 고르기, 계약 | — |

## 3. 수익원
| 수익 ID | 수익원 | 누가 내나 | 금액 (가정, 부가세 별도) | 계약과 관계 | 품이 할 일 |
|---|---|---|---|---|---|
| `REV_01` | **집주인 광고비** (`AD_OWNER_30D`) | 집주인 | 방 1개 30일 **9,900원** | 무관 | 자동 결제 · 게시 |
| `REV_02` | **공인중개사 월 구독** (`AD_AGENT_MONTH`) | 공인중개사 | 월 **5만 원**, 매물 수 제한 없음 | 무관 | 자동 |
| `REV_03` | **상단 노출** (`AD_TOP_7D`) | 둘 다 | 7일 **1만 원**, 방 찾기 맨 위 "⭐ 추천" | 무관 | 자동 |
| `REV_04` | **문의당 과금** (`AD_LEAD`) | 공인중개사 | 한부모 가족 문의 1건 **1,000원**, 월말 모아서 정산 (집주인 광고는 30일 광고비에 포함) | 무관 (문의 기준) | 자동 — 법률 확인 [F-21](common_needFix.md#2-정할-것) |
| `REV_05` | **제휴 수수료** | 이사 · 청소 · 가전 렌탈 업체 | 혜택 메뉴로 소개한 이용 금액의 일부 (업체와 계약) | 방 계약과 무관 | 처음 제휴 계약, 이용 수 정산 |
| `REV_06` | **기관 연계 · 기업 후원** | 지자체 · 지원센터 / 기업 (ESG) | 연 단위 이용 계약 · 통계 보고 / 후원금의 일부를 운영비로 | 무관 | 1년 계약, 통계 · 보고서 보내기 |

- 상품 · 가격은 데이터 파일 `data/ad_products.json`(JSON Schema `schema/ad_products.schema.json`)로 관리 — 코드 수정 없이 바꿈
- 받지 않는 돈 (Won't): 한부모 가족에게 받는 모든 돈, 계약 성사 보수 · 계약 금액의 %, 공인중개사 중개보수 나눠 받기, 일반 배너 · 대출 · 금융 상품 광고, 개인정보 제공 대가

## 4. 계산 예시 (월 · 가정)
| 항목 | 수량 | 단가 | 월 매출 |
|---|---|---|---|
| 집주인 광고 (`REV_01`) | 300개 | 9,900원 | 297만 원 |
| 공인중개사 구독 (`REV_02`) | 50곳 | 5만 원 | 250만 원 |
| 상단 노출 (`REV_03`) | 40건 | 1만 원 | 40만 원 |
| 문의당 과금 (`REV_04`) | 600건 | 1,000원 | 60만 원 |
| 제휴 · 기관 · 후원 (`REV_05` · `06`) | — | — | 50만 원 |
| **합계** |  |  | **약 700만 원** |

고정비: 운영 매니저 1명(광고 확인 · 서류 확인 · 신고 처리 · 상담) 약 300만 원 + 서버 · 본인인증 · 문자 · PG · 세무 약 60만 원 = **월 약 360만 원** → 집주인 광고 150개 + 공인중개사 25곳 수준에서 손익분기.

## 5. 단계별 성장 계획
| 단계 | 목표 | 할 일 |
|---|---|---|
| 1단계 · 출시 | 서울 3개 구, 광고 100개 | 지역 공인중개사 무료 체험 1개월, 맘카페 · 주민센터 · 지원센터에 알림, 제휴 업체 2곳 |
| 2단계 · 확장 | 서울 전체, 광고 500개 | 구독 · 상단 노출 판매, 구청 · 지원센터 연계 계약, 후원 기업 1곳 |
| 3단계 · 넓히기 | 수도권 · 광역시 | 공인중개사 앱 연동, 영어 외 언어 ([F-12](common_needFix.md#2-정할-것)) |

## 6. 결제 경로 (광고주 → 품)
| 경로 | 대상 | 고려할 점 |
|---|---|---|
| 웹 PG (카드 · 계좌 · 간편결제) | 광고비 · 구독 · 상단 노출 · 문의 과금 정산 | 광고 서비스 업종 PG 심사, 구독 정기결제 빌링키, 세금계산서 발행 |
| 계좌 입금 | 공인중개사 월말 정산 | 운영 콘솔 수동 확인 |

- 품은 방값 · 보증금을 받지도 보관하지도 않음 — 결제 · 환불 · 보증금 반환은 광고주와 가족 사이 (`POL_AD_01`)

## 7. 결제 상태
- 광고: `review`(확인 중) → `approved`(결제 기다림) → `live`(게시 중, 기간 끝나면 자동으로 안 보임) → `ended`(내림) / `rejected`(반려)
- 문의 과금: 문의 1건마다 `unpaid` 기록 → 월말 정산 결제 → `paid`

## 8. 예외 처리
- 결제 실패: 기간을 늘리지 않음 (`PAY_402`)
- 같은 날 두 번 결제: 남은 기간 뒤에 이어 붙임 (손해 없음)
- 허위 매물로 강제로 내린 광고: 남은 기간 환불 없음 (광고 약관에 고지)
- 집주인 광고 반려: 결제 전에 확인하므로 환불할 일 없음

## 9. 수익성 지표
| 지표 | 목표 |
|---|---|
| 게시 중 광고 수 | 1단계 100개 → 2단계 500개 |
| 광고 1개당 한부모 문의 수 | 월 2건 이상 (광고주가 계속 내는 이유) |
| 문의 → 계약함 비율 | 15% 이상 |
| 공인중개사 구독 유지율 | 70% 이상 |
| 허위 매물 신고 처리 | 24시간 안 |
