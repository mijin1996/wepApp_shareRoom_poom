## 1. 목적
디자이너 · 프론트엔드 개발자가 질문 없이 구현할 수 있는 화면 명세.

## 2. 디자인 원칙
| 원칙 | 내용 |
|---|---|
| 모바일 먼저 | 대부분 휴대폰 · 퇴근길 한 손 사용. 버튼 최소 48px |
| 쉬운 말 | "전대차" · "청약철회" 같은 말 대신 풀어 쓴 문구 |
| 돈은 크게 | 보증금 · 월 임대료 · 관리비 합계를 카드 맨 위에 |
| 따뜻하지만 차분하게 | 동정 · 불쌍함을 주는 문구 · 사진 금지 |
| 두 언어 | 모든 문구는 문구 시트(`i18n/ko.json` · `i18n/en.json`)에서. 영어는 한국어보다 30% 길어도 안 깨지게 버튼 · 카드 폭 설계. 금액은 "₩230,000 / month"처럼 원화 표기 |
| 서비스 이름 | 로고 · 첫 화면 · 문자 첫 줄은 "품 Poom" 함께. 영문은 Poom (POOM 금지). 영어 소개 문구: "Poom /puːm/ — 'embrace' in Korean" |

### `SCR_LANG_01` 언어 전환
- 오른쪽 위 `[한국어 | EN]` 토글. 누르면 같은 화면 · 같은 입력값 그대로 언어만 바뀜
- 첫 방문: 기기 언어가 한국어가 아니면 영어로 시작

## 3. 화면별 명세

### `SCR_HOME_01` 홈
- `[1]` 제목 "아이와 함께, 이번 주에 들어갈 수 있는 방"
- `[1-1]` **검색창** "어느 동네에서 찾으세요? (지역 · 역 · 학교)" / EN: "Where would you like to live? (area · station · school)" → `SCR_SEARCH_01`
- `[1-2]` 추천 검색 칩: 바로 입주 · 보증금 50만 원 이하 · 초등학교 걸어서 10분 · 엄마 하우스 · 아빠 하우스 · 영어 상담
- `[1-3]` 지역별 둘러보기 (구 목록, 빈방 수 표시) · 학교별 둘러보기
- `[2]` 바로 입주 가능한 방 가로 카드 (최대 6개) → `SCR_ROOM_DETAIL_01`
- `[3]` 이용 방법 3단계: ① 방 고르기 ② 10분 상담 ③ 서명하고 입주
- `[4]` 하단 고정 [긴급 도움] → `SCR_HELP_01`

### `SCR_SEARCH_01` 검색
- `[1]` 입력하면 바로 추천 목록을 종류별로: 📍 지역(구 · 동) · 🚇 역 · 🏫 학교 · 어린이집 · 🏠 하우스 이름 — 한글 · 영문 모두 (예: "Mapo", "Hongik Univ.")
- `[2]` 입력 전: 최근 검색어 (기기에만, [지우기]) + 추천 검색 칩
- `[3]` 고르면 방 찾기 목록 · 지도로 이동, 검색창에 조건이 칩으로 남음 (× 로 빼기)
- `[4]` 결과 0건: "아직 ○○에는 Poom이 없어요" + 가까운 지역 3곳 + [이 지역에 생기면 알림] (`REQ_036`)

### `SCR_ROOM_LIST_01` 방 찾기
- `[0]` **우리 가족** (처음 한 번): 자녀 수 · 나이대 · 성별 → "침실 ○개 이상 방을 찾을게요" — 신청 2단계에 그대로 채워짐
- `[1]` 필터: 지역(구) · 엄마 하우스 / 아빠 하우스 · 보증금 상한 · 월 비용 상한 · **[바로 입주]** 토글
- `[1-1]` 필터 더 보기 (시트): 입주 희망일 · 계약 기간 · 관리비 · 건물 유형(아파트 · 단독 · 빌라) · 계단 없음 / 엘리베이터(유모차) · 전용 욕실 · 놀이방 · 학교 · 어린이집 걸어서 ○분 · 외국인 입주 · 영어 상담 · 주차 — [초기화] [○개 방 보기]
- `[1-2]` [목록 | 지도] 전환 (태블릿 · PC는 나란히)
- `[2]` 카드: ♡ 관심 · 사진 · **침실 수 · "○인 가족까지"** · "월 23만 원 · 보증금 46만 원" · 관리비 · 동 이름 · 역 도보 분 · 입주 가능일 배지(`오늘` / `3일 후`)
- `[3]` 정렬: 입주 빠른 순(기본) · 월 비용 낮은 순 · 학교 가까운 순(학교 검색 시)
- `[4]` 목록 맨 아래 / 결과 적을 때: [이 조건으로 빈방 알림 받기] (`REQ_035`)
- 무한 스크롤 (`cursor`)

### `SCR_MAP_01` 지도로 찾기
- `[1]` 동 단위 묶음 표시 "월 20만 원~ · 빈방 3" (정확한 핀 없음, `POL_SEARCH_01`)
- `[2]` 묶음을 누르면 아래에 그 동의 방 카드 목록
- `[3]` 지도 위 표시 켜기 · 끄기: 🏫 초등학교 · 🧸 어린이집 · 🚇 역
- `[4]` 지도를 옮기면 [이 지역에서 다시 찾기]
- `[5]` 필터 · 우리 가족 조건은 목록과 같이 적용

### `SCR_ROOM_DETAIL_01` 방 상세
- `[1]` 사진 슬라이드 (방 · 공용 주방 · 놀이방 · 욕실)
- `[2]` 비용표: 보증금 / 월 임대료 / 관리비(포함 항목) / 첫 달 낼 돈 합계 / **퇴실 청소비** (보증금에서 빠지는 금액) / 최소 · 최대 계약 기간
- `[3]` 방 정보: 침실 수 · 전용 면적 + 공용 면적 몫 (최저주거기준 충족 가구원 수 표시) · 아이 침대 · 창문 안전장치 · 같은 하우스 가구 수 · 자녀 나이대
- `[4]` 위치: 동 단위 지도 + 근처 어린이집 · 초 · 중 · 고등학교 · 역 · 병원(소아과) · 마트 "걸어서 ○분" (`POL_SEARCH_02`)
- `[5]` 하우스 규칙 요약 (`POL_SAFETY_01` ~ `04`)
- `[5-1]` 방 보기 방법: 방문 · 영상 통화 · **안 보고 바로 계약** 중 선택 가능 표시
- `[5-2]` 입주 후기 (있으면, `POL_SEARCH_05`) · ♡ 관심 · 공유
- `[6]` 하단 고정 [이 방 신청하기] — 공실이 아니면 [빈방 나면 알림 받기], 우리 가족보다 작은 방이면 "가족 수에 비해 작은 방이에요" + [맞는 방 보기] (`POL_ROOM_04`)
  - EN: "This room is too small for your family." / [See rooms that fit]

### `SCR_APPLY_01` ~ `03` 간단 신청
- `[1]` 진행 표시 1/3 · 2/3 · 3/3
- 1단계: 희망 입주일 (달력, 가능일만 활성) · 계약 기간(1 · 3 · 6 · 12개월)
- 2단계: 자녀 수 · 나이대 · 성별 (`POL_PRIVACY_01`) — 이름 · 생년월일 입력칸 없음. 방 찾기의 우리 가족 값이 채워져 있음. 바꿔서 필요 침실이 방보다 많아지면 `ROOM_422` 안내
  - 자녀 5명 이상: "상담으로 더 큰 집을 함께 찾아 드릴게요" (`POL_ROOM_05`)
- 3단계: 연락 가능 시간대 · 상담 언어 (한국어 / English) · 하고 싶은 말 (선택, 200자)
  - **[서류 1장 올리기]**: 가진 것 하나 선택 → 사진 찍기 / 파일 고르기
    - 한국인: 주민등록등본 **또는** 한부모가족 증명서 (주민번호 뒷자리 가리기 안내)
    - 외국인: 외국인등록사실증명 (동거 자녀 표시)
    - 발급 방법 안내 (정부24 · 무인 발급기 · 주민센터)
    - [나중에 올릴게요]: 신청은 되지만 "계약 전까지 꼭 필요해요" 안내
- `[2]` [신청하기]: 필수값 모두 있을 때만 `Active`, 제출 중 스피너 + 버튼 잠금
- `[3]` `APPLY_409`(진행 중 신청 있음) → "이미 진행 중인 신청이 있어요" + [내 집로]

### `SCR_APPLY_DONE_01` 신청 완료
- "신청 완료! 운영 매니저가 2시간 안에 전화드려요." (운영 시간 외: "내일 오전에 전화드려요")
- 서류를 안 올렸으면: "계약 전에 서류 1장이 필요해요" + [지금 올리기]
- EN: "You're all set! We'll call you within 2 hours." / "Please upload one document before signing."

### `SCR_CONTRACT_01` 계약서
- `[1]` 핵심 요약 카드 (기간 · 비용 · 반환 · 퇴실 규칙)를 계약서 원문 위에
- `[1-1]` 영어 사용자: 한국어 원본 | 영어 번역 문단별 나란히 (휴대폰은 위아래), 맨 위 "The Korean original prevails" (`POL_LANG_02`)
- `[2]` 원문 끝까지 스크롤 + **서류 확인 완료**일 때만 [서명하기] 활성. 서류 확인 전: "서류 확인 중이에요" / 미제출: [서류 올리기]
- `[3]` 손가락 서명 → 확인 → `signed`

### `SCR_PAY_01` 결제
- `[1]` 결제 금액 = 보증금 + 첫 달 임대료 + 관리비, 항목별 표시
- `[2]` 수단: 카드 · 계좌이체 · 간편결제
- `[3]` 실패 `PAY_402` → "결제가 안 됐어요. 다른 수단으로 해 볼까요?" (방 24시간 유지 안내)

### `SCR_MOVEIN_01` 입주 안내
- 정확한 주소 · 출입 방법 · 입주 체크리스트 · 운영 매니저 연락처

### `SCR_HELP_01` 긴급 도움 (하단 시트)
- 112 (위급) · 1366 (여성 긴급전화, 24시간) · 129 (보건복지상담) · 1577-4206 (가족상담) — 누르면 바로 걸기
- 영어 화면: 112 · 119 · **1345** (외국인종합안내, 다국어) · **1577-1366** (다누리콜센터, 이주여성 · 다문화가족 다국어 24시간) 을 위에
- 번호는 `data/help_contacts.json`에서 관리 (출시 전 운영 시간 · 언어 재확인)

### `SCR_MY_SAVED_01` 관심 방 · 빈방 알림
- 관심 방 목록 (빈방이 되면 배지) · 저장한 검색 조건 목록 (켜기 · 끄기 · 지우기) · 지역 알림

### `SCR_GUIDE_01` 이용 방법 · 자주 묻는 질문 · 입주 후기
- 입주 절차 5단계 그림 (방 찾기 → 신청 + 서류 1장 → 상담 → 계약 · 결제 → 입주)
- 자주 묻는 질문: 서류 · 보증금 반환 · 퇴실 청소비 · 계약 기간 · 외국인 · 성인 자녀 · 방 크기 기준 · 안전
- 입주 후기 (이름 · 얼굴 · 아이 사진 없음)

### `SCR_ANNOUNCE_01` 공지사항 목록
- 카드: 📌 중요 · 분류 · (영어 화면에서 영어가 없으면 "한국어") / 제목 / 날짜. 중요 공지는 테두리 강조
- 홈 화면: 검색 아래 📌 중요 공지 띠(최대 3개) + [공지 모두 보기 →], 그 아래 "처음이세요? 입주까지 5단계 · 자주 묻는 질문" 바로가기

### `SCR_ANNOUNCE_02` 공지 보기
- 분류 · 제목 · 날짜(고쳤으면 "고침") · 본문(줄바꿈 그대로), [← 공지 목록]

### `SCR_COMMUNITY_01` 묻고 답하기 목록
- 머리글 메뉴 · 아래 탭 "커뮤니티"(🙋), 둘 다 **맨 끝**. 아래 탭은 5칸(홈 · 방 찾기 · 내 집 · 공지 · 커뮤니티) — 280px에서도 한 줄
- 위: 제목 + [✏️ 질문하기], 검색창(초성), 주제 칩(전체 · 입주 · 서류 · 생활 · 하우스 · 아이 · 학교 · 지원 제도 · 기타)
- 카드: 주제 · 해결됨 · 운영팀 답변 · 예시 배지 / 제목 / "엄마 · 4글자 · 날짜 · 답변 n"

### `SCR_COMMUNITY_02` 질문 · 답변
- 질문 본문 → 답변(운영팀 답변이 맨 위, 해결된 답변은 초록 테두리) → 답변 쓰기
- 내 질문이면 답변마다 [👍 도움 됐어요], 다른 사람 글이면 [🚩 신고]. 로그인 전에는 "본인인증하고 글쓰기"

### `SCR_COMMUNITY_03` 질문하기
- 주제 · 제목 · 내용(1000자, 글자 수 표시) + "이름 · 전화번호 · 주소 · 아이 이름은 쓰지 마세요"

### `SCR_PARTNER_01` 집 빌려주실 분
- 대상: 집주인 · 건물주 · 기관 (사회주택 · 지자체). 입력: 지역 · 건물 유형 · 방 수 · 연락처 · 하고 싶은 말 → 대표에게 알림
- 소개: "한부모 가족에게 집을 빌려주세요 — 관리 · 입주자 응대는 Poom이 합니다"
