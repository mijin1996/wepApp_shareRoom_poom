## 3. 환경
Android Chrome · iOS Safari (최근 2개 버전), 데스크톱 Chrome · Edge, 화면 360px ~ 1440px

## 3-1. 결함 처리 흐름
발견 → 보고(의견 · 신고) → 분류(종류 · 심각도 · 우선순위) → 재현(3분 기록 · 화면 위치대로) → 수정(가장 작게 + 자동 테스트) → 확인(테스트판 + 회귀 테스트) → 기록(원인 / 고친 것 / 확인 방법, 상태 `완료`)
- 재현이 안 되면 고치지 않고 `보류` + 필요한 정보를 신고자에게 요청
- 고친 뒤 같은 기능의 `TC_` 와 자동 테스트 전체를 다시 돌림 (회귀)

## 4. 버그 등급
`치명`: 신청 · 계약 · 결제 불가, **주소 · 서류 · 자녀 정보 노출**, 결제 금액 오류 / `높음` / `보통` / `낮음`. **치명 0건이 출시 조건**

## 5. 보안 점검
- 권한 없는 API 호출 차단, 다른 사용자 데이터 조회 불가
- 운영 콘솔 외부 IP 접근 차단 · 2단계 인증
- 배포 사이트에서 `/docs/` 경로가 열리지 않음 (`dist/`만 배포)

## 6. 배포 계획
테스트판에서 확인 → 대표 승인 → 운영판 ([기술·비기능](developer_Tech_NFR.md) §5). 1호점 오픈 2주 전 공개 → 첫 주 운영 매니저 상시 대기, 장애 시 이전 버전 롤백 · 전화 신청 접수로 전환
