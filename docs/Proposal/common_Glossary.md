| 용어 | 뜻 |
|---|---|
| Poom (품) | 서비스 이름. 한국어 "품"(두 팔로 안는 가슴 앞 공간 — 안아 주고 보호하는 곳)을 영어 알파벳으로 쓴 것. 한국어 화면 "품", 영어 화면 "Poom". **표기 규칙:** 로고 · 첫 화면은 "품 Poom" 함께, 영문은 첫 글자만 대문자 Poom (POOM 금지), 영어 소개에 발음 /puːm/ 안내 로마자 표기법상 Pum이지만 영어 속어(pum)와 겹쳐 Poom 사용 |
| 하우스 | 여러 한부모 가구가 함께 사는 집 1채. 엄마 하우스 (`mom`) / 아빠 하우스 (`dad`) |
| 방 | 한 가구(부모 + 자녀)가 쓰는 개인 공간. 계약 · 결제 단위 |
| 최저주거기준 | 국토교통부가 정한 가구원 수별 최소 주거 면적 · 방 수 · 설비 기준. 공공임대 · 주거 지원의 기준 |
| 필요 침실 수 | 부모 1실 + 만 6세 이상 자녀는 부모와 분리 + 만 8세 이상 이성 자녀끼리 분리로 계산한 침실 수 (`POL_ROOM_01`) |
| 의견 · 신고함 | 모든 화면의 [💬 의견 · 신고] 버튼으로 받은 앱 오류 · 민원 · 안전 신고 · 제안을 운영 콘솔에서 상태별로 처리하는 곳 |
| 최근 3분 기록 | 신고 직전 3분 동안의 오류 메시지 · 화면 이동 · 누른 버튼. 기기 메모리에만 있다가 신고할 때만 보냄. 버그 리포트의 "재현 단계" 역할 |
| 심각도 · 우선순위 | 심각도 = 얼마나 나쁜가(치명 ~ 낮음), 우선순위 = 언제 고칠까(P1 이번 배포 ~ P3 나중) |
| 테스트판 · 운영판 | 테스트판 = 출시 전 확인용 주소(화면 구석에 판 표시), 운영판 = 이용자가 쓰는 주소. 운영판은 대표 승인 후에만 |
| 회귀 테스트 | 고친 뒤 다른 곳이 깨지지 않았는지 기존 테스트를 다시 돌리는 것 |
| 지역 수요 | 검색 결과가 0건이었던 지역 · 가족 크기 · 가격대와 "생기면 알림" 신청을 모은 숫자. 다음 하우스 위치를 정하는 근거 |
| 빈방 알림 | 저장한 검색 조건에 맞는 방이 빈방이 되면 보내는 문자 |
| 동 단위 표시 | 지도 · 목록에 하우스를 동 중심점으로만 보여 주는 방식. 정확한 주소는 결제 후 (`POL_SEARCH_01`) |
| 바로 입주 | 오늘부터 7일 안에 들어갈 수 있는 빈방 |
| 간단 신청 | 3단계 입력 + 서류 사진 1장으로 하는 입주 신청 |
| 상담 통화 | 신청 후 2시간 안(운영 시간)에 운영 매니저가 거는 10분 전화. 심사를 겸함. 한국어 · 영어 |
| 확인 서류 | **입주 전**(신청 때 ~ 계약 서명 전)에 내는 1장 — 주민등록등본 또는 한부모가족 증명서, 외국인은 외국인등록사실증명 |
| 외국인등록사실증명 | 외국인의 등록 · 체류 · 동거 가족을 증명하는 서류 (Certificate of Alien Registration). 정부24 · 출입국 · 주민센터 발급 |
| 잡아 두기 (`held`) | 승인 후 72시간 동안 다른 사람이 계약하지 못하게 방을 묶어 두는 상태 |
| 전대 | 집주인에게 빌린 집을 다시 다른 사람에게 빌려주는 것. 집주인 동의 필요 |
| 사회주택 | 공공 지원을 받아 사회적경제 주체가 시세보다 싸게 운영하는 임대주택 |
| 돌봄 품앗이 | 같은 하우스 부모끼리 등하원 · 저녁 돌봄을 번갈아 돕는 것 |
| 안전 주의 | 상담에서 위험(가정폭력 등)이 확인된 입주자 표시. 콘솔 `운영 매니저` 이상만 봄 |
